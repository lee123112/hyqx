# 视文单链路输入（10条）

上传本目录的 `input.zip`，按对应视文链路从M03或平台输入接入环节开始测试。ZIP内有根级manifest、10行JSONL和10个媒体，不能只上传媒体而丢掉配对文本。

解压内容已同时放在本目录，入口为 `02_scene_verified.jsonl`，媒体字段 `video` 使用 `media/` 开头的相对路径。重新压缩时从本目录内选取manifest、入口JSONL和media目录，使它们处于ZIP根级。

本组10个媒体互不重复，媒体和完整原始配对记录均直接取自源数据；未改写描述。

`配对清单.md`便于查看文本与文件，`样本来源清单.json`记录来源。它们是查看材料，不参与ZIP输入；后续算子的输入应使用实际上游输出，不能把这份原始输入当成所有下游节点的直接输入。分数、隔离和待审结果以实际执行为准。
