# 音文单链路输入（10条）

上传本目录的 `input.zip`，按对应音文链路从M03或平台输入接入环节开始测试。ZIP内有根级manifest、10行JSONL和10个媒体，不能只上传媒体而丢掉配对文本。

解压内容已同时放在本目录，入口为 `02_scene_verified.jsonl`，媒体字段 `audio` 使用 `media/` 开头的相对路径。重新压缩时从本目录内选取manifest、入口JSONL和media目录，使它们处于ZIP根级。

本组为4个源音频按已有字幕时间段截取的10个不同片段：中文4条、英文6条。截取不重采样，文本取自对应时间范围的原有字幕，来源和PCM校验见样本来源清单。英文样本用于音文链路兼容性/待审路径测试；当前中文CER门禁对英文可能不适用，不能预期10条都自动通过。

`配对清单.md`便于查看文本与文件，`样本来源清单.json`记录来源。它们是查看材料，不参与ZIP输入；后续算子的输入应使用实际上游输出，不能把这份原始输入当成所有下游节点的直接输入。分数、隔离和待审结果以实际执行为准。
