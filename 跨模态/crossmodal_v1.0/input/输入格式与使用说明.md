# 跨模态单链路输入格式及使用说明

本次按图文、视文、音文各10条整理。三个目录都提供可直接上传的 `input.zip` 和相同解压内容，彼此独立测试。原有all及英文目录未改动。

## 直接使用

- 图文：上传 `图文/input.zip`，10张独立图片＋各自原始描述。
- 视文：上传 `视文/input.zip`，10个独立视频＋各自原始描述，不混入音频字段。
- 音文：上传 `音文/input.zip`，10个不同音频片段＋对应原字幕文本，不混入视频字段。

这三包是M03初筛/平台批次输入的起点。测试某一条模态链时只打开对应模态及其需要的公共节点；每个后续节点接真实上游产物。它们不是M17/M18/M20/M22等节点的独立直测输入，后者需要前序生成的对齐、框、评分或质检结果。

## ZIP组装

```text
input.zip
├─ manifest.json
├─ 02_scene_verified.jsonl
└─ media/
   └─ image/、video/或audio/（按本包模态，只保留一种）
```

manifest必须在根级，`entrypoint`为`02_scene_verified.jsonl`，本包使用`format=crossmodal-manifest-v1`；`artifacts`列出入口和媒体文件。JSONL为UTF-8，每行一个JSON对象，共10行，不是JSON数组。

本包使用的记录字段：

|字段|含义与来源|
|---|---|
|sample_id|每条记录的唯一ID；图文/视文保留原ID，音文片段使用audio_text_01至10|
|text|图片/视频原始配对描述，或音频片段对应的原字幕文本|
|image / video / audio|只使用当前模态对应字段，值为ZIP内媒体的相对路径；不用本机盘符或外层ZIP路径|
|files|与该记录媒体字段对应的modality及path清单|
|license|沿用源记录的可训练标记，不自行改变授权结论|
|source、source_id、batch_id、upstream_version|保留源记录；音文片段的ID和版本增加片段标识，来源仍可追踪|
|metadata|源数据描述、来源、语言等；音文附原始音频路径、截取时间/帧范围及PCM校验|

字段示例（图文）：

```json
{
  "sample_id": "example_01",
  "source_id": "source_example_01",
  "license": "可训练",
  "text": "与媒体对应的文字描述或语音内容",
  "image": "media/image/example.jpg",
  "files": [
    {
      "modality": "image",
      "path": "media/image/example.jpg"
    }
  ]
}
```

视文将`image`及files.modality换成`video`，路径指向视频；音文换成`audio`，text填写该片段对应语音文本。仅改字段名不能把一条数据变成另一模态，应同时提供真实匹配的媒体和文本。

## 取样与预期

图文、视文去除源目录中同媒体重复记录，各选10个独立素材并保留原文；没有人工造错配或写入通过分数。源目录只有4个独立音频，故按原有字幕边界截出10个不同片段，4条中文、6条英文，原文件不改。音文目录清单记录每条的完整文字、来源及截取范围。

本次目标是输入格式及单链路测试，不将原始自然配对承诺为全数超过自动对齐阈值。当前中文CER门禁对英文样本可能不适用；英文样本的待审/不适用状态应按真实规则处理。具体分数与分流须运行对应链路后确认。

每组的`配对清单.md`用于人工查看，`样本来源清单.json`与`input.zip.sha256.txt`用于追溯和传输核验；这些查看材料不在input.zip内。格式/媒体/ZIP检查记录在`_整理记录/输入包整理校验.json`。

## 已执行的输入验证

三个ZIP均通过CRC、JSONL条数/ID唯一性、媒体相对路径和文件完整性检查。图片可解码、10个视频完整解码通过，音频片段PCM与原始音频相应帧区间逐字节一致。

另外已分别通过原版M03的multipart `/predict` 实际调用：图文10→10、视文10→10、音文10→10；均为HTTP 200、status=1、坏行0、缺媒体0。该验证确认输入接入正常，不代表已运行后续评分、人工审核或全链路。原始数据目录及原有all/input.zip整理前后SHA256一致。
