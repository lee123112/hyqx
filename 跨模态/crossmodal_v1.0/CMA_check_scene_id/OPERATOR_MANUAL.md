## 1. 职责

对 #01 放行的批次清单核验**场景编号**，把同一场景下的多模态样本归组，并决定该记录继续走
**融合集**还是**配对集**：

- 有场景编号：核验同一编号下至少 `min_modalities`（默认 2）种模态；
  达标则写入 `scene_id` / `group_id`（`grp-scene-<scene_id>`，供 #11 引用）；
- 模态数不足：**不隔离**，保留在产线中并改走配对集；
- 无编号：按 `scene_id_source` 决定沿用平台编号或由本算子补一个**确定性编号**（只绑定一次）；
- 工具未启用：不核验、不改写，记录原样交给 #03。

## 2. 表1 冻结参数

| 参数 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `enabled` | `false` | 布尔 | 表1 页面控件 1；关闭时配对集任务不执行、记录原样交给 #3 |
| `scene_id_source` | `platform` | `platform` / `generate` | 表1 页面控件 2；场景编号用平台的还是本产线补 |
| `min_modalities` | `2` | `2`–`4` | 表1 页面控件 3；同一场景至少几种模态才算达标 |
| `bind_once` | `true` | 只读冻结 | 补的编号只绑定一次，不复用不重绑 |
| `device_control` | `read_only` | 只读冻结 | 设备并发与故障切换只读采集平台结果，**不做流调度** |
| 模型/权重 | 无 | — | 纯规则型：无模型、无权重、不联网、不产生任何分数 |

上述前三项可被 `/predict` 的请求 `config` 覆盖；其余为只读项，请求携带同名键会**直接配置失败**。

## 3. 输入

- 主输入：#01 放行的工程侧批次清单、来源 ID、批次号、授权结论、上游版本；
- 关键字段：`sample_id`、`scene_id`、各模态登记项；
- 媒体路径必须为素材包内相对路径。

## 4. 输出

| 产物 | 说明 |
| --- | --- |
| `02_scene_verified.jsonl` | 主产物：已核验并写入 `scene_id`/`group_id` 的记录 |
| `02_scene_groups.jsonl` | 场景组汇总（`grp-scene-<scene_id>`） |
| `02_routed_to_pairing.jsonl` | 模态不足、改走配对集的记录（**不隔离**） |
| `02_origin_quarantine.jsonl` | 原始文件问题 → 原始隔离区 |
| `02_rejects.jsonl` | 算子异常清单（不隔离） |
| `02_scene_report.json` | 统计报告 |

记录内结论位于 `processing["02"]`。

## 5. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/uploadFile?uniqueId=` | 上传 zip 素材包或单文件 |
| POST | `/predict` | 执行核验；`isLastOperator` 仍必传用于标记阶段末，[v4.2] 起中间/阶段末响应同构（均返回 `outputFile` + `result`） |
| POST | `/removeFile?uniqueId=` | 幂等清理任务目录 |

**无 `/downloadFile`**。外层响应固定 `{"code","msg","data"}`。

## 6. 依赖

- 运行：`fastapi`、`uvicorn`、`pydantic>=2`、`PyYAML`、`python-multipart`；
- **无模型依赖、无权重、无外部服务**，运行期不联网。

## 7. 资源

CPU 2 核以上 / 内存 ≥ 2 GB；无需 GPU；磁盘按素材包大小计。

## 8. 质量标签与去向

| 场景 | 标签 | 去向 |
| --- | --- | --- |
| 场景组模态数达标 | `流程-场景编号已核验` | 融合集场景组（`fusion_scene_group`） |
| 模态数不足 | `流程-改走配对集` | 保留产线，改走配对集（`pairing_route`） |
| 工具未启用 | `流程-场景核验未启用` | 原样透传 |
| 重复 `sample_id` | `流程-重复样本ID` | 算子异常清单（不隔离） |
| JSON 无法解析 / 缺字段 | `原始文件-无法解析` / `原始文件-缺字段` | 原始隔离区（`raw_isolation`） |

## 9. 与其他算子的关系

- **上游**：#01 接入多模态批次（放行清单）；
- **下游**：#03 数据初筛；#11 生成候选配对（消费 `group_id`）；
- **旧目录关系**：旧 `demo/02_数据初筛` 与本算子职责不同，未复用、未改动；本目录为表1 #02 正式实现；
- **跨算子约束**：本算子只做场景编号核验与归组，**不做隔离判定**（模态不足属流程状态，不得写入样本隔离库）。
